Your Eleven dashboard

Match analysis for Eleven Table Tennis, worked out from the game's own logs. Everything stays on this computer.

你的 Eleven 儀表板

根據遊戲本身的記錄，為 Eleven Table Tennis 做比賽分析。所有資料都留在這部電腦上。

Connect your headset連接你的頭戴裝置

  1. On the headset, open Eleven, then Settings › Network Settings › File Sharing, and start it. It shows an address such as 192.168.1.20:8090. Keep the game open.在頭戴裝置上開啟 Eleven，前往設定 › 網路設定 › 檔案分享並啟動。畫面會顯示一個位址，例如 192.168.1.20:8090。讓遊戲保持開啟。
  2. Type that address here and check the connection. This computer must be on the same Wi-Fi.在這裡輸入該位址，然後檢查連線。這部電腦必須連上同一個 Wi-Fi。
    Headset address頭戴裝置位址
    • Import the logs. The first import reads every log on the headset and takes a minute or two; after that, press Import new logs after each session.匯入記錄。第一次匯入會讀取頭戴裝置上的所有記錄，需要一兩分鐘；之後每次打完球按一下匯入新記錄即可。

    Moving from another computer? 從另一部電腦搬過來？

    No Wi-Fi sharing? Copy the ALL-….log files off the headset another way (a USB cable, a file manager) and use From files… above.
