Your Eleven dashboard

Match analysis for Eleven Table Tennis, worked out from the game's own logs. Everything stays on this computer.

  1. On the headset, open Eleven, then Settings › Network Settings › File Sharing, and start it. It shows an address such as 192.168.1.20:8090.
  2. Open Settings above, enter that address and press Save. This computer must be on the same Wi-Fi.
  3. Press Import new logs. The first import reads every log on the headset and takes a minute or two; after that, press it after each session.

No Wi-Fi sharing? Copy the ALL-….log files off the headset another way (a USB cable, a file manager) and use From files….

Want to look first? The demo is built from made-up matches.

Your logs and results are kept in . Game logs hold your Eleven and Meta account tokens, so keep that folder private.

你的 Eleven 儀表板

根據遊戲本身的記錄，為 Eleven Table Tennis 做比賽分析。所有資料都留在這部電腦上。

  1. 在頭戴裝置上開啟 Eleven，前往設定 › 網路設定 › 檔案分享並啟動。畫面會顯示一個位址，例如 192.168.1.20:8090。
  2. 打開上方的設定，輸入該位址並按「儲存」。這部電腦必須連上同一個 Wi-Fi。
  3. 按匯入新記錄。第一次匯入會讀取頭戴裝置上的所有記錄，需要一兩分鐘；之後每次打完球按一下即可。

無法用 Wi-Fi 分享？用其他方式（USB 線、檔案管理員）把 ALL-….log 檔案從頭戴裝置複製出來，再使用從檔案匯入…。

想先看看？示範是用虛構的比賽製作的。
